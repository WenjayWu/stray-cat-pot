# 2026-06-15 流浪猫窝概念图 v0.3 猫猫元素

本文件夹保存第三轮外观精修概念图，共 4 张。

生成目标：在 A++ 全 3D 打印、无金属、榫卯/滑槽/卡扣连接方向不变的前提下，加入建筑化猫元素，让猫窝比 v0.2 更有记忆点，但仍适合放在园区/小区公共空间。

## 设计约束

- 不改变当前物理功能架构，只做外观符号和维护部件造型探索。
- 猫元素优先融入结构：猫耳屋檐、猫头入口、尾巴把手/锁扣。
- 避免贴纸式装饰、夸张猫脸、大眼睛、胡须、过度爪印。
- 保留 A++ 原则：PETG 全打印硬件，默认无螺丝、无金属合页、无金属角码。
- 标牌保持空白或无字，避免生成错误文字。
