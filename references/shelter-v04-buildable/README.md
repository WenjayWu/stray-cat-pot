## 本轮构造

- **外壳：** 四角柱与墙面中间立向导向节点定位，两列两排墙板从上方插入。下层板先装，上层板随后装，接缝压条与门框最后装。楔块负责防脱，承托与榫肩负责支撑。
- **屋顶：** 中脊沿前后方向，左右两坡各分前后两片，共四片；脊盖与跨缝盖条单独处理。长盖条分段，交会节点需要重叠遮盖，不能把交叉缝直接暴露在雨水中。
- **底盘：** 四块分片，接缝有承托，不能只靠小卡扣悬空承重。框架长件也要分段；搭接轮廓与抗侧向变形留待 CAD 完善。
- **内胆：** 四块浅盘独立落座，逐块从上方提出。四块不能作为整体大抽屉悬空端起；提取位置、搭边缝隙和保温层托底关系需继续设计。
- **布局：** 左偏入口，右侧短挡板，绕过挡板进入主体休息区。挡板为可拆插件，不构成密闭玄关；猫的转身与进入意愿需用 1∶1 样件观察。
- **维护：** 解除防脱约束，抬起组合屋顶，再取浅盘、短挡板与季节插件。组合屋顶的刚度、重量、抓握和抗风揭尚未验证；若组合盖不便抬起，后续考虑逐片拆顶。

HTML 的剖切隐藏屋顶、前墙与右墙以展示内腔；实际日常维护只需开顶。拆分视图说明分组与层次，不是完整的装配仿真：实际墙板沿竖槽下插，拆墙还要先取压条、门框和上口约束。

## 尺寸与假设

单位均为 mm；宽为左右、深为前后、高为竖直。

| 项目 | 本轮概念分配 | 说明 |
| --- | --- | --- |
| 含屋檐外廓 | 约 600 × 520 × 550 | 沿用历史尺度作概念比例，非实地确认 |
| 主体外廓平面 | 约 520 × 440 | 留四周约 40 屋檐 |
| 内腔平面 | 约 450 × 380 | 预留壳体、保温与内衬，不是裸壳几何净值 |
| 内腔净高 | 低处约 350、中脊约 420 | 较历史固定 380 目标调整，需用户与样件确认 |
| 入口净轮廓 | 约 160 × 190 | 门槛约高出内地面 35，圆角拱形 |
| 短挡板 | 约长 130、高 205 | 可移除；保留绕行空间 |
| 离地 / 内地面 | 支脚约 60 / 内地面约 90 | 底盘与浅盘占用其间空间 |
| 屋顶坡度 | 约 16° | 概念几何，不表示防水验证通过 |
| 屋顶分片 | 每片斜面约 313 × 260 | 不含所有榫头、盖条与切片余量 |
| 内胆分片 | 每片约 225 × 190 | 提取与密封构造尚待细化 |

PETG 全打印硬件、尽量无金属连接沿用当前 A++ 路线。新配色与简洁小屋外观为暂拟，用户没有在本轮确认颜色或外观定稿。打印设备、有效成型边界、材料和放置点未重新确认；本轮不使用历史设备规格来宣称适配通过。

屋顶示意的斜面近似计算为 `sqrt(300² + (300 × 75 / 260)²) ≈ 312.2`；取 313 仅便于讨论。零件朝向、突出接口、加强筋和 brim 必须在 CAD 与切片器核对。页面不是尺寸可编辑的 CAD，也不导出生产网格。

## 下一步验证

1. 做 1∶1 空间样件，核实低檐净高、入口、门槛、绕行和转身；特别检查短挡板是否挤占可用空间。
2. 分别建模竖槽＋墙板舌边、上下板搭接＋压条、屋顶跨缝盖条＋脊盖交会节点、内胆搭边＋承托小样。
3. 按实际设备切片，检查装配间隙、长槽摩擦、翘曲、层间受力方向；记录材料、方向、切片设置与测量条件。
4. 核实组合屋顶承托与防脱、支脚稳定、提取动作和屋顶抬起的可操作性。
5. 通过淋水和拆装样件检验接缝、滴水边、层纹渗水及内胆积污，再推进整屋 CAD。
