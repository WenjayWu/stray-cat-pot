# 流浪猫“商品房”设计计划

> 文档版本：v1.0 ｜ 方案方向：A++（全 3D 打印 + 榫卯/胶接）｜ 计划对应产物版本：v0.1 原型

**版本方向：** 方案 A++：全 3D 打印硬件 + 榫卯/胶接连接猫屋  
**目标：** 设计并制作一款模块化、可移动、防寒防水、外观正式的户外流浪猫窝。项目定位不是临时纸箱窝，而是可维护、可复制、可解释的“商品房”级别猫屋，适配园区/小区屋檐、墙角等半户外场景。

**核心方向：** 所有硬件结构件优先使用 PETG 3D 打印，包括外壳、墙体、底盘、屋顶、门框、支脚、压条、锁扣、通风件、检修口和内胆盘。  
v0.1 不优先使用金属材料，不把热熔螺母、螺丝、金属合页作为默认方案。结构连接优先采用类似木作家具的榫卯、插接、滑槽、燕尾、卡扣、楔块、搭接和胶接。外购材料只保留保温用品、软垫、稻草、密封条/胶条、胶水等非结构打印材料。

**核心约束：**
- 园区未明确允许但未禁止 → 外观需正式、整洁、非垃圾感，便于解释和搬离。
- 放置位置多为屋檐下、墙角、灌木边 → 仍需防水、防风、防潮、避晒。
- 设计优先级不是最低成本 → 优先节省时间成本和设计集成成本。
- 硬件尽量统一为 3D 打印件 → 减少裁板、外购板材适配和多材料装配问题。
- 已确认打印设备为拓竹 H2D，最大成型体积 350mm × 320mm × 320mm → 整屋必须分件打印，单件模型需留出边界余量。
- 已确认喷嘴 0.4mm，最低层高 0.08mm；v0.1 大件优先使用 0.2mm 左右层高，细节/卡扣样件再使用更细层高。
- 耗材未耗尽时可连续打印 → 允许多天打印，但仍需控制单件失败成本。
- 需可单人搬动 → v0.1 总重目标暂定 8-12kg 内，后续按实测修正。
- 维护件必须可拆 → 屋顶、内胆盘、挡风帘、软装不能胶死。
- 大外壳允许半永久胶接 → 但主体结构强度应来自榫卯、搭接和框架几何，而不是只靠胶水。

## 阶段一：需求确认与参考收集（1-2 天）

### Task 1.1 实地摸底

- 测量或估计园区流浪猫体型：肩高、体长、胸宽，确定最小内部空间。
- 记录候选放置点：屋檐、墙角、灌木边、背风处，拍摄环境光照、雨水路径、积水情况、风向和人流。
- 观察周边是否已有猫窝、纸箱、投喂点，判断猫的活动路线和园区容忍度。
- 确认放置点是否会挡路、影响清洁、靠近车流或容易被物业收走。
- 记录可搬运路径和放置空间，避免设计尺寸过大导致实际搬不进去。

### Task 1.2 参考收集

重点收集以下维度：
- 普通宠物猫窝：入口大小、内部空间、软垫结构、安全感设计。
- 户外流浪猫窝：保温、防水、防潮、挡风、离地、清洁维护。
- 木作家具连接：榫卯、燕尾、滑槽、楔块、搭接、插销的受力和装配逻辑。
- 3D 打印模块化结构：分件方式、卡扣寿命、层间强度、接缝防水、打印方向。
- 户外 PETG 结构：UV 老化、低温韧性、翘边、层纹渗水、胶接表现。
- 大连气候：四季分明、空气湿润、降水集中在夏季、季风明显且风大；冬季雨雪少但干冷风大，1 月最冷。设计重点是冬季防风保温、夏季防雨散热、春秋防潮。

### Task 1.3 需求矩阵

| 需求 | 优先级 | 验收标准 |
|------|--------|----------|
| 全打印硬件路线 | P0 | 外壳、底盘、屋顶、门框、支脚、锁扣、内胆等硬件均优先 3D 打印 |
| 非金属默认连接 | P0 | v0.1 不依赖螺丝、热熔螺母、金属合页完成主体装配 |
| 可居住内部空间 | P0 | 单猫可转身、蜷缩、趴卧，不显著空旷 |
| 防水外壳 | P0 | 雨后内部无明显渗水，入口不直灌 |
| 底部离地防潮 | P0 | 离地 5-8cm，底部不直接接触潮湿地面 |
| 全包保温 | P0 | 底、四壁、顶均可放置保温层，优先 20-30mm XPS 或等效材料 |
| 四季可调内装 | P0 | 冬季保温件可加厚，夏季可减少软装并增加通风，春秋重点防潮 |
| 可维护内装 | P0 | 内胆盘、稻草/软垫可抽出、更换、晾晒 |
| 可维护屋顶 | P0 | 屋顶可打开或可拆，不破坏主体结构 |
| 单人搬运 | P0 | 一人可搬动，整屋目标暂定 8-12kg 内 |
| 外观正式 | P1 | 非纸箱/垃圾感，可打印铭牌和维护说明 |
| 可封闭后门 | P1 | 根据实际风险决定是否保留，默认后门/检修口可封闭 |
| 夏季透气组件 | P2 | 可替换通风件或通风雨帽 |
| 水碗支架 | P2 | 可作为外挂打印模块，不影响主体防水和搬运 |

> 说明：双出口不直接列为 P0。双出口利于逃生，但会降低保温、防风和防水。v0.1 默认做“可封闭后门/检修口”，是否长期打开由测试决定。

## 阶段二：方案确认（1 天）

### Task 2.1 主方案：A++ 全打印硬件 + 榫卯/胶接连接

```text
主结构：PETG 分件打印外壳、墙体、底盘、屋顶、支脚、门框、内胆盘
连接方式：榫卯、燕尾、T 型槽、滑槽、搭接边、楔块、卡扣、插销、旋转锁片
密封方式：几何搭接 + 密封条/胶条 + 打印压条 + 局部户外胶/硅胶
保温软装：XPS、铝箔保温棉、稻草、宠物垫、防潮垫等外购
默认不使用：热熔铜螺母、螺丝、金属合页、金属角码
```

选择 A++ 的理由：
- 省掉裁板和板材适配，减少多材料尺寸误差。
- 结构接口由建模统一控制，迭代时只改模型和打印件。
- 外观完整度更高，更符合“商品房”定位。
- 硬件件坏了可重打替换，便于后续形成标准件库。
- 成本不是 v0.1 第一约束，时间成本和设计成本更关键。

### Task 2.2 暂定尺寸

尺寸需要根据实地摸底和打印机成型尺寸调整。v0.1 暂定：

- **目标猫体型：** 正常成年猫体型，主要参考狸花、三花、小白猫等常见流浪猫。
- **内部净空间：** 宽 45cm × 深 38cm × 高 38cm，适合 1 只成年流浪猫舒适蜷缩，也可短时容纳 2 只小体型猫。
- **入口：** 宽 15-16cm × 高 18cm，入口底边离内部地面约 4-6cm。
- **整体外形：** 约 60cm × 52cm × 55cm，含打印墙体、保温层、屋顶外挑和支脚。
- **支脚高度：** 5-8cm。
- **屋顶外挑：** 四周外挑 3-5cm，入口侧优先 5cm。
- **后门/检修口：** 默认可封闭，不作为常开逃生口，后续根据观察决定。

### Task 2.3 打印边界

- 打印机为拓竹 H2D，最大成型体积 350mm × 320mm × 320mm。
- 单件模型建议控制在 330mm × 300mm × 300mm 以内，给 brim、热胀冷缩、取件和切片留余量。
- 整体 60cm 级猫屋必须拆成模块：墙板至少左右/上下分件，底盘和屋顶至少 2-4 块分件。
- 大件首选 0.4mm 喷嘴、0.2mm 左右层高；卡扣、滑槽、锁片、连接样件可用 0.12mm 或 0.08mm 验证细节。
- 优先设计连接试样，不直接打印整套外壳。
- 耗材未耗尽可连续打印，因此允许多天打印；但每个模块仍建议控制在可接受失败成本内，避免单件过大导致返工代价过高。
- 墙板不追求实心，优先用壳体、加强筋、空腔、肋板控制重量。
- PETG 颜色待定；v0.1 优先选择浅色或中性色，减少夏季日晒吸热，同时让外观看起来更像正式设施。

## 阶段三：结构设计（3-5 天）

### Task 3.1 分件模块

**底盘**
- 分块打印，采用燕尾/滑槽拼接。
- 外侧可胶接补强，内部集成排水坡、内胆定位槽、支脚连接位。
- 底部设计离地支脚和防潮空气层。

**墙板**
- 四面打印墙板自带搭接边、保温卡槽和密封槽。
- 墙板之间用角柱滑槽定位，再用楔块、插销或卡扣锁止。
- 大墙板采用背部加强筋和空腔结构，避免厚实打印导致耗时和重量过高。

**角柱**
- 作为四面墙板的榫槽节点。
- 内置竖向滑槽，让墙板从上方或侧方插入。
- 角柱承担主要立向和侧向载荷，卡扣只负责防脱。

**屋顶**
- 分块斜顶，采用重叠搭接、滴水边和外挑檐。
- 屋顶必须可拆或可开，不能胶死。
- 优先使用打印滑轨、旋转锁片、楔块锁止或柔性打印铰链，不默认使用金属合页。

**入口模块**
- 整体打印门框、圆角防刮边、雨檐和挡风帘槽。
- 与前墙用卡扣/滑槽连接，必要时局部胶接非维护边。
- 入口偏侧面，避免风雨直通主休息区。

**后门/检修口**
- 优先使用滑盖、旋转锁片或柔性打印铰链。
- 默认可封闭，兼顾清洁、检查和应急。

**内胆盘**
- 抽屉式打印托盘，承载保温层和软装。
- 可整体抽出清洁，避免 XPS、稻草或垫子难以维护。
- 内胆盘边缘倒圆角，避免刮伤猫。

**通风件**
- 打印雨帽式通风孔，避免闷湿。
- 通风孔不形成穿堂风，孔位避开入口直线风路。

**铭牌**
- 外侧打印正式说明牌：
```text
公益临时猫屋
可移动 / 定期清洁 / 不影响通行
如需调整位置请联系：____
```

### Task 3.2 榫卯/卡扣设计原则

- 户外受力连接避免只靠脆弱小卡扣，采用大接触面积榫槽承担载荷。
- 卡扣只负责防脱，承力由搭接面、榫肩、框架肋承担。
- 榫槽、滑轨、燕尾、楔块预留 0.2-0.5mm 装配间隙，按打印机精度试样调整。
- 胶接面做粗糙纹理、凹槽、孔洞或肋条，提高胶水机械咬合。
- 外部接缝采用“上盖下、外盖内”的搭接方向，减少雨水顺缝进入。
- 需要拆的模块只做机械锁止，不胶死。
- 允许半永久胶接的模块包括底盘分块、墙板大拼缝、非维护外壳缝。

### Task 3.3 胶接与密封策略

- 半永久结构可使用户外结构胶、中性硅胶或适合 PETG 的胶水。
- 防水胶不承担主要结构强度，结构强度仍由榫卯/搭接几何提供。
- 维护件不胶死：屋顶、内胆盘、挡风帘、软装、检修盖必须可拆。
- 屋顶、墙体、入口接缝优先用迷宫式搭接和滴水边解决进水，胶只做补强。
- 密封条/胶条可以作为非金属耗材使用，配合打印压条压紧。

### Task 3.4 保温与内装

- 大连气候判断：冬季雨雪少但干冷风大，夏季潮湿多雨且降水集中，春季干燥多风，秋季降雨减少但降温快。
- 保温策略不能做成永久封死，应采用“打印壳体 + 可替换保温插件 + 可抽出内胆盘”的四季模块。
- **冬季模式：** 底、四壁、顶使用 25-30mm XPS 或等效保温层；入口使用挡风帘；内胆铺稻草或防潮宠物垫；重点处理风从入口和通风孔倒灌。
- **春秋模式：** 保留底部和背风侧保温，减少顶部/侧壁部分保温；重点防潮、易晾晒、易更换内装。
- **夏季模式：** 减少或移除厚保温层，保留遮阳外壳和底部防潮；更换通风雨帽或透气件，避免内部闷热，但仍防暴雨斜打。
- XPS 不裸露作为最终内壁，放入打印内胆盘或薄内衬后方，避免猫抓碎泡沫。
- 内底结构建议：
```text
打印底盘
+ 防潮空气层
+ XPS 保温层
+ 抽屉式打印内胆盘
+ 稻草 / 防潮宠物垫 / 可替换软垫
```
- 墙体结构建议预留 20mm 与 30mm 两档保温层卡槽或压片位置，方便冬季加厚、夏季减薄。
- 顶部保温层必须可拆，避免夏季积热；底部保温层优先常驻，因为地面返潮比空气低温更稳定。
- 不建议长期使用易吸水且不易干的厚毛巾。

### Task 3.5 防水、防风与通风

- 屋顶斜度 ≥15°，四周外挑 3-5cm，入口侧优先做更深雨檐。
- 屋顶分块缝必须做重叠搭接，不允许雨水直落到拼缝。
- 入口内侧可设计短挡风玄关或转向挡板。
- 底部可预留小排水/冷凝水孔，但孔位要避开软垫区域，并防止雨水倒灌。
- PETG 层纹可能渗水，外壳外侧可考虑局部涂层、胶封或后处理。

## 阶段四：原型制作（3-5 天）

### Task 4.1 连接试样优先

正式打印整屋前先打印小样：
- 燕尾槽 + 楔块。
- 竖向滑槽 + 墙板边。
- 屋顶搭接缝 + 滴水边。
- 卡扣/插销/旋转锁片。
- 胶接纹理小片。

测试装配间隙、拆装手感、卡扣寿命和是否容易断层。

### Task 4.2 纸板或低填充打印 mockup

正式 PETG 长时间打印前，先做 1:1 纸板或低填充打印形态样件，用来验证：
- 内部空间是否合适。
- 入口位置和大小是否合理。
- 屋顶打开是否方便。
- 单人搬运时抓握点是否自然。
- 放置点是否显得突兀或挡路。
- 分件线是否合理，是否方便打印和组装。

### Task 4.3 打印正式 PETG 结构件

初始切片建议：
- 材料：PETG。
- 设备：拓竹 H2D，成型体积 350mm × 320mm × 320mm。
- 喷嘴：0.4mm；大件优先 0.2mm 层高，连接样件/卡扣/锁片可用 0.12mm 或 0.08mm 做精度验证。
- 单件尺寸：建议不超过 330mm × 300mm × 300mm。
- 墙体/大壳件：3-4 壁线，15-25% gyroid/cubic，使用加强筋控重。
- 受力件/卡扣/支脚/锁片：4-6 壁线，30-50% 填充。
- 榫槽、滑轨、卡扣件优先增加壁线，减少单纯高填充。
- 卡扣件避免沿层间方向受拉，必要时调整打印方向。
- 大件使用 brim，降低翘边风险。
- 所有猫可接触边缘倒圆角，避免刮伤。

### Task 4.4 组装流程

1. 组装底盘分块，燕尾/滑槽定位，允许对半永久缝胶接补强。
2. 插入支脚或支脚模块，确认离地和稳定性。
3. 安装四根角柱，确认竖向滑槽方向。
4. 从滑槽插入四面墙板，用楔块、插销或卡扣锁止。
5. 安装入口模块、雨檐和挡风帘槽。
6. 安装后门/检修口滑盖或旋转锁片。
7. 放入 XPS 或等效保温层。
8. 插入抽屉式内胆盘。
9. 安装屋顶分块、搭接边、滴水边和可拆锁扣。
10. 铺入稻草或可替换软垫。
11. 安装打印铭牌。

## 阶段五：测试与迭代（1-2 周）

### Task 5.1 连接试样测试

- 测试燕尾槽、滑槽、楔块、卡扣、旋转锁片的装配间隙。
- 反复拆装 10 次，观察卡扣白化、断裂、松动和磨损。
- 调整模型公差，形成适合当前打印机的连接参数。

### Task 5.2 胶接测试

- 用 PETG 小样测试候选胶水的粘接强度、防水性和低温后状态。
- 胶接小样至少包含平面胶接、粗糙纹理胶接、孔洞咬合胶接三种。
- 记录哪种胶水适合作为半永久补强，哪种只适合防水密封。

### Task 5.3 装配与强度测试

- 不使用金属紧固件完成整屋装配，检查是否松动、变形、难拆。
- 单人搬运测试：搬起、转向、放下，确认重心和抓握点。
- 顶部轻压和侧向推压，确认屋顶、角柱和墙板不明显位移。
- 边缘检查：猫可接触区域无尖角、毛刺、硬刮边。

### Task 5.4 防水测试

- 模拟小雨 10-15 分钟，重点检查搭接缝、胶接缝、屋顶分块缝、入口周边和层纹渗水。
- 测试后打开屋顶，检查保温层、内胆盘和软装是否潮湿。
- 若有渗水，优先调整搭接方向、滴水边、密封条槽、打印压条和入口雨檐。

### Task 5.5 维护测试

- 确认屋顶、内胆盘、挡风帘、软装可在不破坏主体的情况下取出和复位。
- 检查检修口是否能单手打开/关闭，闭合后是否防风。
- 检查半永久胶接区域是否影响必要维护。

### Task 5.6 室外试放

挑选一个屋檐下或背风墙角，静置 3 天观察：
- 是否有猫进入痕迹：毛发、脚印、稻草压痕。
- 内部是否潮湿、冷凝或异味。
- 园区人员是否移动、清理或反馈。
- 雨后是否积水，支脚是否稳定。

1 周后跟进：
- 稻草/软垫是否受潮、压实或被拖出。
- PETG 连接件是否松动、开裂、白化或变形。
- 胶接和密封区域是否老化、开裂或脱落。
- 猫使用频率和进入路径。

根据结果输出 v0.2 改动项。

## 风险与权衡

| 风险 | 概率 | 缓解 |
|------|------|------|
| 大件打印翘边或失败 | 中高 | 分件设计、brim、控制单件尺寸，先打试样 |
| 层纹渗水 | 中 | 外侧涂层/胶封，屋顶搭接和滴水边优先 |
| 榫槽公差不合适 | 高 | 先打印连接试样，建立 0.2-0.5mm 公差基准 |
| 卡扣断裂 | 中 | 卡扣只防脱，承力交给榫肩和搭接面 |
| 胶接 PETG 强度不足 | 中 | 胶接只补强/密封，结构强度靠几何连接 |
| PETG 户外 UV 老化 | 中 | 关键件加厚，后续评估 ASA/PC、外涂层或遮阳位置 |
| 全打印导致重量增加 | 中 | 空腔、加强筋、非实心墙板，控制在可搬范围 |
| 园区以“乱放杂物”为由清理 | 中 | 外观正式、可移动、留联系牌，避开通道和清洁路线 |
| 猫不进入 | 中 | 入口不要过大，内部保持暗、干、暖；先放在猫常走路线附近 |
| 内垫受潮变冷 | 中 | 使用可替换材料，定期检查；优先稻草或防潮宠物垫 |
