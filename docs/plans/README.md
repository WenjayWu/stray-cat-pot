## 记录约定

- 文件名使用英文小写 kebab-case；版本化计划可使用 `<topic>-plan-v1.md`，后续版本保留历史。
- 说明目标、适用方案/版本、约束、待验证假设、步骤和验收条件；涉及尺寸与试验时记录单位、方向和条件。
- 将实际过程、观察和反馈写入 [logs/](../logs/README.md)，在计划中链接相关记录。
- 不将计划中的预期结果直接标记为已验证；状态更新应能追溯到证据。
