| 位置 | 内容 | 当前入口 |

参考方案的图片、预览、模型、原始说明和生成记录仍随 [references/](../references/README.md) 对应方案保存；评审日志链接对应方案，不重复保存资产。暂不增设更深层分类。

## 计划与日志如何衔接

- 计划说明准备怎么做；日志说明实际做了什么、发现什么。`STATUS.md` 概括当前进度，并链接详细记录。
- 日志按一次有意义的事件记录，不要求每日流水账；方案讨论只整理关键意见、决定和待验证项。
- 明确区分用户确认、设计假设、计算、试样验证与整屋使用反馈；观察与推断分别说明。
- 反馈促成调整时链接到更新后的计划或方案；保留历史观察，后续验证另行补充并标注日期。
