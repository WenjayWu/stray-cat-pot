## 记录约定

- 按一次有意义的事件记录，文件名使用 `YYYY-MM-DD-<topic>.md`；日期采用实际事件日期，后续补充另标日期。
- 方案讨论记录关键意见、决定、理由与待验证项，不要求保存完整聊天或每日流水账。
- 说明对象及版本、目的、条件、过程、观察/证据、结论与后续动作；链接对应计划、方案和照片等资产。
- 打印与装配记录注明材料、设备、打印方向、切片设置、配合与测量条件；使用反馈注明场景、时间与观察方法。
- 明确区分已确认事实、假设、计算、实测和推断；未做的验证直接注明。
- 保留原始观察；纠正或后续验证用注明日期的补充或新记录，并相互链接。反馈改变设计时链接更新后的计划或方案。
